# LangChain 메모리 정리 (ch08memory.ipynb)

> 모든 예제는 `langchain_classic`, `langchain_openai`, `langchain_community` 조합으로 실제 import 확인 완료 (에러/예외 없음). LLM 호출이 필요한 메모리(토큰/엔티티/KG/요약 계열)는 `.env`에 `OPENAI_API_KEY`가 설정되어 있어야 동작합니다.

---

## 1. ConversationBufferMemory

**핵심 개념**
- 가장 기본적인 메모리. 사람의 입력(human)과 AI의 답변(ai)을 짝지어 그대로 저장.
- 모든 대화 내용을 누적 저장하므로, 대화가 길어지면 토큰 사용량이 계속 늘어난다.
- `return_messages=True`를 주면 문자열이 아니라 `HumanMessage`/`AIMessage` 객체 리스트로 반환된다.

```python
from langchain_classic.memory import ConversationBufferMemory

memory = ConversationBufferMemory()

memory.save_context(
    inputs={"human": "안녕하세요, 비대면으로 은행 계좌를 개설하고 싶습니다. 어떻게 시작해야 하나요?"},
    outputs={"ai": "안녕하세요! 계좌 개설을 원하신다니 기쁩니다. 먼저 신분증을 준비해 주시겠어요?"},
)

# 문자열 형태로 히스토리 조회
print(memory.load_memory_variables({})["history"])

# 메시지 객체 형태로 반환
memory = ConversationBufferMemory(return_messages=True)
memory.save_context(
    inputs={"human": "네, 신분증을 준비했습니다."},
    outputs={"ai": "감사합니다. 신분증 사진을 업로드해 주세요."},
)
memory.load_memory_variables({})["history"]  # [HumanMessage(...), AIMessage(...)]
```

## 2. ConversationBufferWindowMemory

**핵심 개념**
- 대화가 너무 많이 쌓이면 입력 토큰 허용 범위를 넘길 수 있으므로, 최근 `k`개의 대화(윈도우)만 기억.
- 새 대화가 추가되면 가장 오래된 항목부터 삭제되고 최신 메시지가 그 자리를 채운다(슬라이딩 윈도우).

```python
from langchain_classic.memory import ConversationBufferWindowMemory

memory = ConversationBufferWindowMemory(k=2, return_messages=True)

memory.save_context(
    inputs={"human": "비대면으로 계좌를 개설하고 싶습니다."},
    outputs={"ai": "네, 먼저 신분증을 준비해 주세요."},
)
memory.save_context(
    inputs={"human": "신분증을 준비했습니다."},
    outputs={"ai": "사진을 촬영해 업로드해 주세요."},
)
memory.save_context(
    inputs={"human": "사진을 업로드했습니다."},
    outputs={"ai": "인증번호를 입력해 주세요."},
)
memory.save_context(
    inputs={"human": "인증번호를 입력했습니다."},
    outputs={"ai": "본인 인증이 완료되었습니다."},
)

# k=2 이므로 가장 최근 2턴(마지막 2쌍)만 남는다
memory.load_memory_variables({})["history"]
```

## 3. ConversationTokenBufferMemory

**핵심 개념**
- 윈도우(대화 턴 개수)가 아니라 **토큰 수** 기준으로 최근 대화를 잘라서 유지.
- `max_token_limit`을 넘어서면 오래된 대화부터 제거.
- 토큰 계산을 위해 내부적으로 `llm`(토크나이저)이 필요하다.

```python
from dotenv import load_dotenv
from langchain_classic.memory import ConversationTokenBufferMemory
from langchain_openai import ChatOpenAI

load_dotenv()

llm = ChatOpenAI(model_name="gpt-4.1-mini")

memory = ConversationTokenBufferMemory(
    llm=llm, max_token_limit=150, return_messages=True
)

memory.save_context(
    inputs={"human": "공작 기계 설치 방법을 알려주실 수 있나요?"},
    outputs={"ai": "모델 번호를 알려주시겠어요?"},
)
memory.save_context(
    inputs={"human": "모델 번호는 XG-200입니다."},
    outputs={"ai": "220V 전원 상태를 확인해 주세요."},
)
# ... 대화가 이어질수록 max_token_limit(150)을 넘는 오래된 대화는 자동으로 삭제됨

memory.load_memory_variables({})["history"]
```

## 4. ConversationEntityMemory

**핵심 개념**
- 대화 전체를 저장하는 게 아니라, 대화 속 **엔티티(사람, 장소, 사물 등 핵심 정보)** 를 추출해 저장.
- 엔티티는 대화나 데이터에서 특정한 의미를 갖는 핵심 정보를 뜻함(예: 이름, 직업, 관계 등).
- `ConversationChain`과 `ENTITY_MEMORY_CONVERSATION_TEMPLATE` 프롬프트를 함께 사용해야 엔티티 추출·요약이 자동으로 이루어진다.

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain_classic.chains import ConversationChain
from langchain_classic.memory import ConversationEntityMemory
from langchain_classic.memory.prompt import ENTITY_MEMORY_CONVERSATION_TEMPLATE

load_dotenv()

llm = ChatOpenAI(model_name="gpt-4.1-mini", temperature=0)

conversation = ConversationChain(
    llm=llm,
    prompt=ENTITY_MEMORY_CONVERSATION_TEMPLATE,
    memory=ConversationEntityMemory(llm=llm),
)

conversation.predict(
    input=(
        "테디와 셜리는 한 회사에서 일하는 동료입니다."
        "테디는 개발자이고 셜리는 디자이너입니다."
        "그들은 최근 회사에서 일하는 것을 그만두고 자신들의 회사를 차릴 계획을 세우고 있습니다."
    )
)

# 대화 내용이 그대로 저장되는 게 아니라, 중요한 정보(엔티티)만 추출되어 저장됨
conversation.memory.entity_store.store
```

## 5. ConversationKGMemory

**핵심 개념**
- Knowledge Graph(지식 그래프)를 활용해 대화 속 관계 정보를 저장하고 조회.
- 엔티티 간의 관계(누가 누구인지, 어디에 사는지 등)를 그래프 형태로 축적해두었다가, 질문이 들어오면 관련된 트리플만 꺼내 컨텍스트로 제공.
- `langchain_classic.memory`에서 바로 가져오면 동작은 하지만 최신 권장 경로는 `langchain_community.memory.kg`이다(둘 다 import 자체는 성공).

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain_classic.memory import ConversationKGMemory  # 최신 권장: langchain_community.memory.kg

load_dotenv()

llm = ChatOpenAI(temperature=0)

memory = ConversationKGMemory(llm=llm, return_messages=True)

memory.save_context(
    {"input": "이쪽은 Pangyo 에 거주중인 김셜리씨 입니다."},
    {"output": "김셜리씨는 누구시죠?"},
)
memory.save_context(
    {"input": "김셜리씨는 우리 회사의 신입 디자이너입니다."},
    {"output": "만나서 반갑습니다."},
)

memory.load_memory_variables({"input": "김셜리 씨는 누구입니까?"})
```

## 6. ConversationSummaryMemory

**핵심 개념**
- 대화가 진행되는 동안 전체 대화를 그때그때 LLM으로 요약하고, 원문 대신 **요약본**을 메모리에 저장.
- 대화가 길어져도 저장되는 텍스트 양이 크게 늘지 않아 토큰 절약에 유리하지만, 세부 디테일은 손실될 수 있다.

```python
from langchain_classic.memory import ConversationSummaryMemory
from langchain_openai import ChatOpenAI

memory = ConversationSummaryMemory(
    llm=ChatOpenAI(model_name="gpt-4.1-mini", temperature=0),
    return_messages=True,
)

memory.save_context(
    inputs={"human": "유럽 여행 패키지의 가격은 얼마인가요?"},
    outputs={"ai": "유럽 14박 15일 패키지의 기본 가격은 3,500유로입니다."},
)
memory.save_context(
    inputs={"human": "여행자 보험은 포함되어 있나요?"},
    outputs={"ai": "네, 모든 여행자에게 기본 여행자 보험을 제공합니다."},
)

# 원문 대신 요약된 내용이 저장됨
print(memory.load_memory_variables({})["history"])
```

## 7. ConversationSummaryBufferMemory

**핵심 개념**
- `ConversationSummaryMemory` + `ConversationBufferMemory`의 결합형.
- 최근 대화는 원본 그대로 유지하고, `max_token_limit`을 넘어가는 오래된 대화만 요약본으로 변환해 저장.
- 최근 문맥의 디테일은 살리면서도 토큰 사용량은 억제할 수 있다.

```python
from langchain_openai import ChatOpenAI
from langchain_classic.memory import ConversationSummaryBufferMemory

llm = ChatOpenAI()

memory = ConversationSummaryBufferMemory(
    llm=llm,
    max_token_limit=200,
    return_messages=True,
)

memory.save_context(
    inputs={"human": "유럽 여행 패키지의 가격은 얼마인가요?"},
    outputs={"ai": "유럽 14박 15일 패키지의 기본 가격은 3,500유로입니다."},
)
memory.save_context(
    inputs={"human": "여행 중에 방문할 주요 관광지는 어디인가요?"},
    outputs={"ai": "파리 에펠탑, 로마 콜로세움 등을 방문합니다."},
)
# 누적된 토큰이 max_token_limit(200)을 넘으면 오래된 대화부터 요약본으로 압축됨

print(memory.load_memory_variables({})["history"])
```

## 8. VectorStoreRetrieverMemory

**핵심 개념**
- 대화 내용을 벡터 스토어(FAISS 등)에 임베딩하여 저장.
- 호출될 때마다 전체 대화 순서를 따지지 않고, 현재 쿼리와 **가장 관련성 높은 상위 K개** 문서만 검색해서 반환(유사도 기반 검색, 시간 순서 비추적).
- `FAISS`, `InMemoryDocstore`는 `langchain_classic`에서도 import는 되지만 deprecation 경고가 뜨며, 최신 권장 경로는 `langchain_community.vectorstores` / `langchain_community.docstore.in_memory` 이다.

```python
import faiss
from langchain_openai import OpenAIEmbeddings
from langchain_classic.docstore import InMemoryDocstore   # 최신 권장: langchain_community.docstore.in_memory
from langchain_classic.vectorstores import FAISS           # 최신 권장: langchain_community.vectorstores
from langchain_classic.memory import VectorStoreRetrieverMemory

# 임베딩 모델 정의
embeddings_model = OpenAIEmbeddings()

# 벡터 스토어 초기화 (OpenAI 임베딩 차원 = 1536)
embedding_size = 1536
index = faiss.IndexFlatL2(embedding_size)
vectorstore = FAISS(embeddings_model, index, InMemoryDocstore({}), {})

retriever = vectorstore.as_retriever(search_kwargs={"k": 1})
memory = VectorStoreRetrieverMemory(retriever=retriever)

memory.save_context(
    inputs={"human": "자기소개 부탁드립니다."},
    outputs={"ai": "저는 컴퓨터 과학을 전공한 신입 개발자입니다."},
)
memory.save_context(
    inputs={"human": "프로젝트에서 어떤 역할을 맡았나요?"},
    outputs={"ai": "백엔드 개발자로서 RESTful API를 구현했습니다."},
)

# 쿼리와 가장 관련 있는 상위 k개 문서만 반환
print(memory.load_memory_variables({"human": "면접자 전공은 무엇인가요?"})["history"])
```

## 요약 비교표

| 메모리 종류 | 저장 기준 | LLM 호출 필요 여부 |
|---|---|---|
| ConversationBufferMemory | 전체 대화 원문 | ❌ |
| ConversationBufferWindowMemory | 최근 k턴 원문 | ❌ |
| ConversationTokenBufferMemory | 최근 토큰 한도 내 원문 | ✅ (토큰 계산용) |
| ConversationEntityMemory | 대화 속 핵심 엔티티 | ✅ |
| ConversationKGMemory | 엔티티 간 관계(지식 그래프) | ✅ |
| ConversationSummaryMemory | 전체 요약본 | ✅ |
| ConversationSummaryBufferMemory | 최근 원문 + 이전 요약본 | ✅ |
| VectorStoreRetrieverMemory | 벡터 유사도 상위 K개 | ✅ (임베딩용) |
